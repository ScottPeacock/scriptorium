# Scriptorium

An open-source iOS reader for [Grimmory](https://github.com/grimmory-tools/grimmory),
the self-hosted library for ebooks, comics and audiobooks.

If you self-host your library specifically so that nobody else holds your
reading data, the app you read it in shouldn't be a black box either.
Scriptorium is that app: no accounts, no analytics, no third-party services —
it talks to your server and nothing else.

> **Status: early development.** Server connection works; the library browser
> and reader are in progress. Not yet on the App Store.

## What it does

- Connects to your own Grimmory server — nothing in between
- Browses your libraries, shelves, series and authors
- Reads EPUBs, with reading position synced back to the server

Reading position is the part worth explaining. Grimmory stores EPUB progress as
an [EPUB CFI](https://idpf.org/epub/linking/cfi/) generated by
[foliate-js](https://github.com/johnfactotum/foliate-js), and its web reader,
Kobo sync and KOReader sync all resolve against that same stored value.
Scriptorium runs foliate-js too, so positions round-trip exactly: stop reading
mid-paragraph in your browser, pick up on your phone in the same place, and the
reverse. A reader built on a different engine could only approximate that.

## Requirements

- iOS 17 or later
- A Grimmory server you can reach, with a local (non-OIDC) account

## Building

```
brew install xcodegen
xcodegen generate
open Scriptorium.xcodeproj
```

`Scriptorium.xcodeproj` is generated from `project.yml` and is not committed —
regenerate it after pulling changes that touch the project structure.

To run the tests:

```
xcodebuild -project Scriptorium.xcodeproj -scheme Scriptorium \
  -destination 'platform=iOS Simulator,name=iPhone 17' test
```

### API fixtures

Decoding is tested against real server responses rather than assumptions about
Grimmory's Java DTOs. To refresh them against your own server:

```
./Tools/capture-fixtures.sh http://your-server:6060 your-username
```

## Relationship to Grimmory

Scriptorium is an independent client. It is not affiliated with or endorsed by
the Grimmory project, and it talks to Grimmory's documented
[REST API](https://grimmory.org/) — chiefly the `/api/v1/app/*` endpoints that
exist for exactly this purpose.

Grimmory itself is AGPL-3.0. Scriptorium is a separate work that communicates
with it over HTTP, and is licensed independently.
